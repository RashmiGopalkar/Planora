# Smarty Study Buddy (Python Edition)

A modern study dashboard rewritten in **Python + Streamlit**.

## Features
- Friendly buddy chat with motivation prompts
- Session tracking with quick complete/end actions
- Study/Homework mode switching
- Subject progress sliders
- Flashcards with expandable answers
- Timetable and event planner
- Points, style upgrades, goals, and session history

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
